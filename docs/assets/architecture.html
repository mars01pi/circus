Circus · 执行架构

从任务输入到产物导出：宿主凭据、工具授权、执行边界与清理归属。

01 / Rust 逐层拒绝越界

  • 协议帧、路径、期限和任务预算先校验。
  • 未配置连接与未显式授权的工具直接拒绝。
  • 创建后 inspect 实际后端策略，缺项即失败。
  • 失败不会触发隐式扩大权限。

02 / 模型密钥留在宿主

  • 容器 network=none，不连接外部网络。
  • 模型请求通过现有进程标准流转发。
  • 宿主验证模型与路径，再发起 HTTPS 请求。
  • 真实 API key 不进入沙箱。

03 / 确认回收再报成功

  • AgentRunner 负责单任务协议与产物。
  • lifecycle 统一拥有后端状态和销毁。
  • 取消后继续等待最终清理结果。
  • pending 可重试；unknown 需宿主核查。

当前 Agent 路径：Docker + runc。containerd / Kubernetes 是独立库后端；HTTP API 暂不提供 Agent 任务接口。
